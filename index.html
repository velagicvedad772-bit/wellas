Relativna molekulska masa, broj čestica, molarna masa i njihova veza — zadaci riješeni korak po korak.
1. Prije računanja — tri veze koje rješavaju sve zadatke
1 · Relativna molekulska masa
Mᵣ = Σ Aᵣ
Zbroj relativnih atomskih masa svih atoma u formuli. Bez jedinice — omjer prema 1/12 mase atoma ¹²C.
2 · Množina i broj čestica
N = n · Nᴀ
n u mol, N kao broj jedinki, Nᴀ ≈ 6,022 × 10²³ mol⁻¹. Obrnuto: n = N / Nᴀ.
3 · Molarna masa
M = m / n
M u g mol⁻¹ brojčano jednaka Mᵣ. Izvedeno: m = n · M i n = m / M.

Kako brojimo atome
Indeks izvan zagrade množi sve unutra: (NH₄)₂ = 2 N i 8 H. Tačka u hidratu znači „plus“: ·6H₂O dodaje šest molekula vode.
Zašto uz Aᵣ i Mᵣ nema jedinice?
Jer su to omjeri — masa atoma ili molekule podijeljena s 1/12 mase atoma ¹²C. Omjer dviju masa je čisti broj.
Zadatak 3 · Od mola do čestica — množina puta Avogadrova konstanta
a) Koliko molekula sadrži 1 mol H₂O?
N = 1 mol · Nᴀ = 6,022 × 10²³
b) Koliko molekula sadrži 0,50 mol CO₂?
N = 0,50 · 6,022 × 10²³ = 3,011 × 10²³
c) Koliko atoma sadrži 2,00 mol Cu?
N = 2,00 · 6,022 × 10²³ = 1,204 × 10²⁴
d) Množina uzorka s 3,011 × 10²³ molekula O₂?
n = N / Nᴀ = 3,011 × 10²³ / 6,022 × 10²³ = 0,500 mol
e) 25 g kalcijum karbonata CaCO₃ — množina tvari
M = 40,08 + 12,01 + 3·16,00 = 100,09 g/mol
n = m / M = 25 g / 100,09 g/mol = 0,250 mol
f-a) 72,99 g željezo(III) hlorida FeCl₃ — broj čestica
M = 55,85 + 3·35,45 = 162,20 g/mol · n = 72,99 / 162,20 = 0,450 mol
N = n · Nᴀ = 0,450 · 6,022 × 10²³ = 2,71 × 10²³
f-b) 0,200 mol natrijum hlorata NaClO₃ — množina je zadana, masa nije potrebna
N = n · Nᴀ = 0,200 · 6,022 × 10²³ = 1,204 × 10²³
Zadatak 5 · Masa, množina i molarna masa
Kad mol stane na vagu
a) Masa 1,00 mol O₂
M(O₂) = 2·16,00 = 32,00 g/mol · m = n·M = 32,00 g
b) Masa 0,600 mol etanske kiseline C₂H₄O₂
M = 60,05 g/mol · m = 0,600 · 60,05 = 36,03 g
c) Množina u 9,8 g sulfatne kiseline H₂SO₄
M = 98,08 g/mol · n = 9,8 / 98,08 = 0,10 mol
d) Broj molekula u 18,0 g H₂O
n = 18,0 / 18,02 ≈ 1,00 mol · N = n·Nᴀ ≈ 6,02 × 10²³
Jedan mol bilo koje tvari sadrži 6,022 × 10²³ jedinki. Mijenja se samo masa.

Provjeri razumijevanje — tačno (T) ili netačno (N)?
N Mᵣ ima jedinicu g mol⁻¹ — Mᵣ je omjer bez jedinice; g mol⁻¹ pripada molarnoj masi M.
T M(H₂O) ≈ Mᵣ(H₂O) brojčano — isti broj 18,02, ali različite veličine i jedinice.
T Dvostruko n → dvostruko m — m = n · M, a M je za istu tvar stalna.
